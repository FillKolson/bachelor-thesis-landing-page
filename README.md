# Інформаційна система тестування знань на базі чат-бота в месенджері Telegram

## Бакалаврська робота

### Загальна інформація

**Назва (українською):** Інформаційна система тестування знань на базі чат-бота в месенджері Telegram

**Назва (англійською):** Information System for Knowledge Testing Based on a Telegram Chatbot

**Університет:** Сумський державний університет (СумДУ)

**Факультет:** Електроніки та інформаційних технологій (ЕлІТ)

**Автор:** Шевченко Кирил Олексійович

### Мета роботи

Розробити функціональну інформаційну систему тестування знань на базі чат-бота в месенджері Telegram, що демонструє володіння сучасними технологіями веб-розробки (React, Vite), системою контролю версій Git Flow та принципами створення доступних і SEO-оптимізованих інтерфейсів.

### Опис проєкту

Проєкт демонструє практичне застосування сучасних веб-технологій (React, Vite) та методології Git Flow при створенні адаптивного, SEO-оптимізованого лендінгу для представлення бакалаврської роботи.

**Ключові слова:** Telegram, чат-бот, тестування знань, інформаційна система, React, Vite, Git Flow, лендінг, SEO, доступність, адаптивність, веб-розробка, бакалаврська робота.

### Технології та інструменти

- **Фронтенд:** React, Vite, CSS3
- **Система контролю версій:** Git з методологією Git Flow
- **SEO:** Open Graph, Twitter Card, Schema.org
- **Доступність:** ARIA-атрибути, семантична розмітка
- **Адаптивність:** Mobile-first підхід, темна/світла тема

### Функціональні можливості

- Перемикання між світлою та темною темою
- Повністю адаптивний дизайн
- Підтримка доступності (screen readers, keyboard navigation)
- SEO-оптимізація для пошукових систем
- Структуровані дані (Schema.org)
- Швидка загрузка та оптимізація

### Перевірка роботи

1. Запустити проєкт: `npm run dev`
2. Перевірити адаптивність через Chrome DevTools
3. Перемкнути тему кнопкою 🌙/☀️
4. Перевірити SEO через "View Page Source"
5. Перевірити доступність через Tab navigation

### Результат

Готовий сучасний лендінг для бакалаврської роботи, що демонструє володіння сучасними веб-технологіями та методологією Git Flow. Проєкт може використовуватися як портфоліо-робота для подальшого професійного розвитку.

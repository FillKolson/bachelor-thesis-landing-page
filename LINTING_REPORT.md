- ✅ Проверяется форматирование (Prettier)

- ✅ Проверяются типы (TypeScript)

### ✅ Интегрирована в процесс сборки

**`package.json` scripts:**

```json
{
  "build": "npm run check && vite build"
}
```

**Workflow:**

1. `npm run build` → запускается `npm run check`
2. Если `check` успешно → запускается `vite build`
3. Если `check` ошибка → сборка не выполняется

# Генерація документації

Цей проєкт документується за допомогою **JSDoc** (коментарі у форматі `/** ... */` у файлах `*.js` / `*.jsx`).

## Вимоги

- Node.js + npm

## Встановлення залежностей

```bash
npm install
```

## Згенерувати HTML-документацію

Команда згенерує документацію у папку `docs/api`.

```bash
npm run docs:generate
```

Після цього відкрийте `docs/api/index.html` у браузері.

## Перевірка якості документації

У проєкті підключено `eslint-plugin-jsdoc`. Мінімальна перевірка доступна командою:

```bash
npm run docs:lint
```

## Що саме документувати

- Публічні (експортовані) компоненти/функції/класи.
- Обробники подій з нетривіальною логікою або side effects.
- Будь-які частини, що працюють з `localStorage`, DOM-атрибутами, інтеграціями.
